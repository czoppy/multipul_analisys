# Thesis Reading Workspace

A workspace to track reading materials for my master thesis.

## Structure

```
multipul_analisys/
├── reading_list.md       # Main tracker — add links and files here
├── papers/               # Drop PDF files here
├── notes/                # One markdown file per paper/source
└── README.md
```

## Workflow

1. **Add a source** → Edit `reading_list.md`, fill in a new row in the table
2. **Drop a PDF** → Place it in `papers/`, then reference the filename in the table
3. **Take notes** → Create a file in `notes/` (e.g., `notes/smith2023.md`)
4. **Update status** → Change the Status column as you read

## Status values

| Symbol | Meaning        |
|--------|----------------|
| `todo` | Not started    |
| `read` | In progress    |
| `done` | Finished       |
| `skip` | Skipping       |
